Where each part of the work runs

The Skill delegates only to registered NAS experts. It calls no outside service and needs no key. One part depends on the owner's setup.

Registered NAS experts
  • Phone-backup photosread only unless you ask for the optional archive step; the originals are not renamed or deleted
  • OCR and picture checkdone by the NAS photo expert (built-in models)
  • Keepsake folders and albumnew copies, one album per child, created after approval
  • Digest fileone new Markdown file per batch; a child's words are stored only if the parent types them
  • Run memorythe fridge-door-done file tag and the digests, including the “Next run starts from” date; nothing else
  • No downloadsno scripts, no API key, no outside service
Depends on the NAS owner Summaries and the digest text are written by Uliya. They run on whichever model the owner set up for Uliya: a local model, or a cloud model the owner chose. A translated copy of the digest and the art journal are made only if the parent asks.

Third-party components: none. All names, schools and phone numbers in examples and test material are invented.
