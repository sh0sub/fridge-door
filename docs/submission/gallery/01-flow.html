How it works

From a photo in the backup to a dated to-do

One weekly request. Nothing is created until the parent has seen the preview and said yes, and the NAS has approved each write.

“Sort out this week's school papers.” → find the last digest → confirm folder, period, children → read each photo → preview, with a question about what the child said → approve → report with the next due item. Say “continue” for the next 12 photos.
Next week
The digest says Next run starts from a date, and the next run starts there. Every photo it listed carries fridge-door-done, so only new ones are read. Unticked boxes are carried over.
Child's words
At the preview you can tell it what a child said about a drawing. The words are kept as typed, next to that drawing in the digest.
Art journal
Ask “Make Mina's art journal” and it lists her Artwork lines from the saved digests in date order. Saved as a file only if you want.
When it can't read
Blurred photos are listed by name, not guessed. Albums follow Artwork - Mina. Originals stay in place unless you ask for the optional archive step.
